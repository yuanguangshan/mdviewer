# v4.18 菜单顶部「常用功能」：按使用频率取前 5

## 做了什么

「⋯」菜单最上面多了一区「常用功能」，显示**用得最多的 5 项**，其余按原分组排。

初始默认（还没积累数据时）：

| 顺序 | 项 | key |
|---|---|---|
| 1 | 📤 存到 NAS（上传到 Knowly） | `act:nas-upload` |
| 2 | 📥 从 NAS 取回（下载为 md） | `act:nas-download` |
| 3 | 📚 添加到文库 | `act:addtolib` |
| 4 | 🌗 主题设置 ▸ | `sub:theme` |
| 5 | 📃 导出纯文本（.txt） | `act:txt` |

默认项种子计数为 1：用户真用过的项达到 2 次就会顶掉它们。**默认值是起点，不是特权。**

## 实现要点

- **计数只在一个地方做**：`document` 上的 capture 监听，抓所有 `[data-act]` / `[data-action]` 点击。
  菜单、左上角快捷菜单、命令面板（内部走 `el.click()`）三条路径最终都经过这里，不会漏也不会重复计。
- **不复制菜单结构**：渲染时按 key 找到原始按钮 `cloneNode(true)`，样式与行为天然一致；
  点击克隆项照样走原来的委托处理器。
- **数据只存本机** `localStorage['md-act-freq']`（最多保留 50 个键）：这是使用习惯，不是文档内容，不上传。
- **排序下沉内核** `rankFreq(map, topN, exclude, prefer)`：
  次数降序 → 平手时按 `prefer` 给定顺序（默认五项的顺序，避免退化成字母序）→ 再按 key。
  平手顺序必须稳定，否则每次打开菜单顺序都在跳。
