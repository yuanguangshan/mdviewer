# v4.15 菜单重构 + 命令面板

## 为什么改

「⋯」菜单里已经 70 多项、没有分组标题，手机上要翻很久才能找到东西。同时有一批文案不一致（`复制Markdown` 缺空格、`导出 html` 与 `导出 Markdown` 大小写混用、三个齿轮图标、`保存 / 另存为` 与实际不符）。

## 菜单：按用途分组

```
命令面板（Ctrl/Cmd+Shift+P）
编辑     查找替换 / 重命名 / 文本宏命令 / 正文字号与颜色
插入     插入图片 / 设置背景图片 / 插入播客播放器
AI       AI 智能助理
文档     添加到文库 / 发布到博客 / 文档转播客 / 存到 IMA
导出     Markdown / HTML / PDF / 纯文本 / 复制三种格式 / 分享链接
同步与备份  存到 NAS / 从 NAS 取回 / 从网址打开 / 备份全库 / 从备份恢复
设置     格式 / 格式刷 / 主题 / 开关设置 / 诊断信息
```

文案统一规则：**动词在前、格式带扩展名、图标不重复**。改动举例：

| 旧 | 新 |
|---|---|
| 📋 复制Markdown | 📋 复制 Markdown |
| 导出 html / 导出为 txt 文件 | 导出 HTML（.html）/ 导出纯文本（.txt） |
| 🖼️ 设置背景图片（与「插入图片」同图标） | 🏞️ 设置背景图片 |
| 📥 从备份恢复（与「从 NAS 下载」同图标） | ♻️ 从备份恢复 |
| 🗄️ 备份全库（与「文库」同图标） | 📦 备份全库（.zip） |
| 💾 保存到 IMA 笔记 / 📤 上传到 NAS | 💾 存到 IMA / 📤 存到 NAS |
| 🅱 加粗 / 🇮 斜体 | B 加粗 / I 斜体 |
| 💾 保存 / 另存为 (Ctrl+S) | 保存 (Ctrl+S)（Ctrl+S 本来就只保存） |
| Designed by yuanguangshan. | 由 苑广山 设计 |
| 苑广山的在线文库（写死在 HTML） | 本地文档库（可用 localStorage `md-lib-sub` 覆盖） |

**PDF 导出补上了菜单入口**，快捷键从 `Ctrl+P`（浏览器打印键）改为 `Ctrl+Alt+P`。

## 命令面板

- 快捷键 `Ctrl/Cmd+Shift+P`，菜单第一项也能进
- **不维护第二份命令表**：直接扫描菜单 DOM 的 `data-act` / `data-action`，执行时 `el.click()` 复用原有接线 → 以后加菜单项自动出现在面板里
- 模糊匹配下沉到内核 `fuzzyScore()`（含单测）：中文子串、跳字搜索、大小写不敏感
- ↑↓ 选择、Enter 执行、Esc 关闭

## 其他修复

- **表格 Tab 跳格**：光标在表格行内时 Tab 跳下一格、Shift+Tab 上一格；行末跳到下一行首格；末行末格自动补一行空表格行
- **编辑态大纲跟随光标**：原来编辑模式下目录永远高亮第一个标题
- **Esc 关闭菜单**：原来只能点外面
- **Mac 快捷键提示**：启动时把 title 里写死的 `Ctrl+` 统一改成 `⌘`
- **状态栏语气统一**：`就绪` → `待编辑`；`✓ 已存文库` → `✓ 已保存 · 文库`
- 触摸设备隐藏快捷键提示（手机上 `Ctrl+E` 既按不到也看不懂）
